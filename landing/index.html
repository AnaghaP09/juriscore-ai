Quickstart

Download, install Bun, start.

Nothing else to install. Works on macOS, Linux and Windows.

# 1 · install Bun (Windows: see the Run page)
curl -fsSL https://bun.sh/install | bash

# 2 · unzip the package
unzip juriscore-2026.10.01.zip
cd juriscore-2026.10.01

# 3 · start it (Windows: start.cmd)
./start.sh
  ➜ Listening on: http://localhost:8080/

# to connect a model, follow the Setup page

Full steps for every system are on the Run page. The same checks run in CI before every release.

How it works

Four steps around every model call.

  1. 01

    Screen the input

    Look for sensitive data, secrets and prompt attacks.

  2. 02

    Hide or block

    Hide what must not leave. Stop the request if policy says so.

  3. 03

    Check the claim

    Compare it with the real source. Match, drift or cannot determine.

  4. 04

    Keep the receipt

    A record of the decision and the evidence, for you to keep.
